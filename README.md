# Zara'a Agro Holdings — Website

Static homepage for Zara'a Agro Holdings with a scroll-scrubbed hero brand film.

## Run locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Structure

- `index.html` — page markup, styles and scroll logic
- `support.js` — component runtime (loads React from a CDN)
- `assets/` — logo, images and the brand film
